## 5. On job-posting dates

- **LinkedIn is the most reliable signal**: an exact "Posted X hours/minutes/days ago" (or
  "X weeks/months ago") per listing — this pass's tables above are built directly from it.
- **Indeed** also shows "Posted X days ago" / "nieuw", but several listings (e.g. large
  NTT DATA batches) showed a flat "Posted: 6 August 2026" for every result, which looks
  more like a default freshness label than a true post date — treat Indeed dates as
  indicative, LinkedIn's as more trustworthy.
- Specialist recruiter sites (Eursap) show a **contract/permanent start date** or an
  internal **Job ID**, not the date the ad went live — don't read those as posting dates.
- **Glassdoor and Jobat blocked automated fetching this pass** (403 / fetch failure) —
  browse those two directly in a browser rather than relying on this document.
- StepStone shows a "geplaatst op" (posted on) date but its listing pages timed out on
  automated fetch (JS-rendered / bot-resistant) — check manually in a browser.
